Tangerine Test Cases
1. Login:
    a. Log in and logout. 
    b. Select last login and username from the dropdowns, then log in. 
    c. Clear login history from the menu and log out. There should be no saved servers in the login server dropdown.
2. Submit a form - Open, fill and submit a form. Check whether it reached the server
3. Use a form offline - Download a form and disconnect from internet. Open, fill and submit a form. Reconnect to the internet and check if it reached the server.
4. Use a group offline - Download a group and disconnect from the internet. Open the group and then open, fill and submit a form. Reconnect to the internet and check if it reached the server.

RESPECT test cases - https://github.com/UstadMobile/Respect/wiki/Compatible-app-review-procedure-for-inclusion-in-default-catalog
1. Login - Login to the Respect server and add the Tangerine app (copy RESPECT manifest link from the Tangerine app).
2. Submit forms/tasks from the RESPECT app:
    a. Login as a Respect admin in the RESPECT app and create a Respect assignment with a student added to it. Add two Tangerine forms as tasks to the assignment in two different ways, via Assignments page (add using '+ Assignment' button) and via the lesson/learning-unit/form details page (add using 'Assign' button).
    b. Login as the Respect student and open, fill and submit the first task/form (assigned in the previous step). Form should have opened in the Tangerine app.
    c. Uninstall the Tangerine app.
    d. In the RESPECT app open, fill and submit the next task/form. It should have opened in a webview. 
    e. Open Assignments in the Respect app and verify that both the tasks/forms are set to completed in the assignment (results sent via xAPI-IPC).
3. Use offline:
    a. Login as a Respect admin in the RESPECT app and create a Respect assignment with a student added to it. Add two Tangerine forms as tasks to the assignment in two different ways, via Assignments page (add using '+ Assignment' button) and via the lesson/learning-unit/form details page (add using 'Assign' button).
    b. Download a Tangerine form in Respect and disconnect from the internet. 
    c. Login as a Respect student and open the first form via assignment from Respect. 
    d. It should open in the Tangerine app. 
    e. Submit the form. 
    f. Reconnect to the internet and check the task is completed in the Respect assignment. 
    g. Disconnect from the internet and uninstall the Tangerine app and open the next form/task via the assignment from Respect. 
    h. It should open in a webview. 
    i. Submit the form. Reconnect to the internet. 
    j. Check the form/task is completed in the Respect assignment.
